# カメラ設置とプレビュー

## ブラウザでの設置プレビュー

`crowded-edge-preview`は、`device.ini`と同じカメラ番号・解像度・JPEG品質で映像を表示します。映像はRaspberry Piのループバックアドレスだけで公開し、ノートPCからSSHトンネルを通して確認します。校内ネットワークへカメラ映像を直接公開しません。

まず自動送信サービスが停止していることを確認します。1台のカメラをプレビューと自動送信から同時に開くことはできません。

```bash
sudo systemctl stop crowded-edge.service
```

ノートPCからポート転送付きでSSH接続します。

```bash
ssh -L 8765:127.0.0.1:8765 nnct-pi@nnct-oc-rp-01.local
```

接続したRaspberry Pi上でプレビューを開始します。

```bash
/home/nnct-pi/CrowdedDetector/edge/.venv/bin/crowded-edge-preview \
  --config /etc/crowded-detector/device.ini
```

ノートPCのブラウザで`http://127.0.0.1:8765/`を開きます。三分割の補助線を見ながら画角を調整し、終了時はRaspberry Pi側で`Ctrl+C`を押します。

## 厚紙で作る設置台

壁へカメラを直接貼らず、二重にした板目台紙で「背板・棚板・左右の三角補強」を作ります。

1. 背板はカメラ幅の3倍程度、棚板はカメラを載せても前後に余裕がある寸法にします。
2. 棚板の先端を上へ折り返して落下防止の縁を作ります。
3. 背板と棚板の左右を三角形の厚紙でつなぎ、棚板が下へ折れないようにします。
4. 角度は、カメラの下へ折り重ねた厚紙のくさびを入れて調整します。角度が決まってからカメラ台座を養生テープで棚板へ固定します。
5. USBケーブルはカメラのすぐ近くで背板へ固定し、少したるみを残します。ケーブルの重さをカメラへ掛けません。

可能なら、壁ではなく既存の棚・ロッカー・窓枠などの水平面へ設置台を置く方が安全です。壁へ付ける場合は次を守ります。

- 壁とテープの相性を目立たない場所で確認する
- 背板を広くし、養生テープを上辺・左右・斜め方向へ複数本使う
- カメラとは別に、ひもや追加のテープで落下防止を設ける
- USBケーブルを30～50cm間隔で固定し、端子へ引張力を掛けない
- 人の頭上、避難経路、扉の可動範囲には設置しない
- 本番前に同程度の重さで30分以上保持できることを確認する

YOLOの誤検出と二重計数を減らすため、人物入りポスター、鏡、強い逆光をなるべく画角から外します。2台で同じ会場を撮る場合は、床の境界線や通路などを基準に画角を分け、重複領域をできるだけ作らないようにします。
